# Güvenlik

İmzalı güncelleme doğrulaması veya veri bütünlüğüyle ilgili açıkları herkese açık Issue içinde ayrıntılarıyla paylaşmayın. GitHub Security bölümündeki private vulnerability reporting özelliğini kullanın.

İmzalama anahtarı sadece GitHub Actions secret'ında bulunur. PR kontrolleri bu anahtara erişmez. İçerik yayınları yalnızca main üzerinden elle başlatılır. Uygulamaya gömülen anahtar herkese açık doğrulama anahtarıdır.

Bu ilk sürüm bağımsız bir güvenlik denetiminden geçmemiştir.
